# 💄 Glowify Cosmetics Website

Welcome to **Glowify** — a stylish and fully responsive cosmetics website designed to bring out the glow in every user. This project highlights elegant visuals, smooth animations, and a delightful user experience — built entirely with **HTML, CSS, and JavaScript**.

---

## 🌸 Overview

**Glowify Cosmetics** is a front-end web project showcasing a beauty and skincare brand. The website features a modern design, interactive carousel, animated statistics, testimonials, and popups for offers and contact details.

It serves as a perfect example of a responsive and interactive website using only client-side technologies.

---

## ✨ Features

* 💅 **Fully Responsive Layout** — adapts beautifully to all devices.
* 🎠 **Auto-Playing Carousel** — displays promotions and highlights dynamically.
* 📊 **Animated Stats Counter** — shows live numbers for customers, products, and experience.
* 💖 **Interactive Popups** — includes contact and special offer modals.
* 🌈 **Smooth Scroll & AOS Animations** — enhances the user interface.
* 🌸 **Modern Aesthetic Design** — with clean typography and bright visuals.
* ⏳ **Custom Loader Animation** — engaging spinner while the page loads.
